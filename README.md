# ZOMATO-DATA-ANALYSIS

Zomato Restaurant Expansion Strategy - Excel Analysis Project
📌 Project Overview
This repository contains an Excel-based data analysis for Zomato's restaurant expansion strategy. The goal is to identify optimal locations, cuisines, and restaurant types for Zomato to onboard new partners using structured Excel workflows.

🎯 Objectives
✔ Location Analysis – Identify high-demand, low-supply areas for expansion
✔ Cuisine Gap Analysis – Find popular cuisines with limited restaurant availability
✔ Pricing & Restaurant Type Insights – Determine optimal price points and formats
✔ Competitor Benchmarking – Compare Zomato’s coverage vs. competitors
✔ Demand Forecasting – Predict growth areas using historical trends
